# 我的学习进度

通过 Node.js 一键启动后，网页会把学习状态、代码草稿、错题笔记、知识文章阅读状态和自定义输入保存到 `learning.json`。该文件可以提交到你自己的 fork；API Key 和 AI 对话不会出现在这里。

第一次打开时，如果浏览器已有进度，会保存到文件。如果浏览器与文件都有不同的数据，页面会让你先导出备份，再选择使用哪份数据。不要在冲突提示出现后直接清除浏览器数据。

每次修改后约一至两秒自动保存。结束练习时可以点击页面顶部的“立即保存”，看到保存成功后再提交：

```bash
git add progress/learning.json
git commit -m "记录今天的刷题进度"
git push -u origin HEAD
```

进度文件里的代码和笔记会跟随 Git 提交；你的 fork 若公开，提交的内容也会公开。请只把愿意保存到仓库的学习内容写进草稿和笔记。

换电脑后克隆自己的 fork，安装 Node.js 18 或更高版本并启动，进度会从文件恢复。清空当前浏览器的数据不会删除这个文件。若要同步另一台电脑的新进度，先保存并提交当前修改，再拉取更新，最后刷新网页。

文件采用有缩进的 JSON，以便查看差异。合并 Git 冲突时，请先备份，确认 JSON 完整后再启动。页面遇到文件解析失败或版本冲突时会停止覆盖文件。
